# Decisions

One numbered log of what was decided, by whom, why, and where it lives. A rule is explained in [DOMAIN-RULES.md](DOMAIN-RULES.md); this page says where it came from. Questions that still wait for an answer are in [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md).

**State** of a decision:

- **Confirmed**: Carlos (SACM) said it, or the SACM process documentation says it.
- **Assumed**: Claude decided it while building, from the procedure, the Service Mapping Workspace or the real data, under Carlos's go-ahead of 11 Nov 2026. Carlos may reverse it. Most of these are one line in a file in `checks/`, so reversing needs no code change.
- **Replaced**: a later decision changed it. The row says which one.

Numbers never change and are never reused. A new decision gets the next free number, in the section where it belongs.

Pull request and commit numbers up to version 0.38.0 refer to the private archive of this repository (D286).
