# Triage labels

The skills speak of five triage roles. This repository uses the default label for each one.

| Label in mattpocock/skills | Label in our tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Someone must look at this issue |
| `needs-info` | `needs-info` | Waiting for more information from the person who wrote it |
| `ready-for-agent` | `ready-for-agent` | Fully described, an agent can build it |
| `ready-for-human` | `ready-for-human` | A person must build it |
| `wontfix` | `wontfix` | Will not be done |

When a skill names a role (for example "apply the AFK-ready triage label"), use the label of this table.

The labels are not created on GitHub yet. `/triage` adds a label the first time it needs it.
